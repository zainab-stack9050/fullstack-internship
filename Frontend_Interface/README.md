# Task 1 — Responsive Frontend Interface

A fully responsive Task Manager UI built with vanilla **HTML, CSS, and JavaScript** — no frameworks, as required by the project brief.

## Live Features
- Add, complete, and delete tasks
- Filter tasks by All / Active / Completed
- Light & dark mode toggle
- Circular progress ring showing % of tasks completed
- Active/Completed stats breakdown
- Confetti celebration when all tasks are completed
- Fully responsive — mobile-first layout, expands at tablet (768px) and desktop widths

## Tech Used
- **HTML5** — semantic structure (`header`, `nav`, `main`, `aside`, `section`, `footer`)
- **CSS3** — CSS Grid (page layout) + Flexbox (components), CSS variables for theming, `conic-gradient` for the progress ring, mobile-first media queries
- **JavaScript (Vanilla)** — DOM manipulation, event delegation, state + render pattern
